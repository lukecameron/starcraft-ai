## Recommendation

Use McRave as the provisional first reusable development baseline: it is C++, MIT-licensed, and pinned at `7d1719a22d8b896f957abae50e2ea5efff974fe2`. BASIL's matching active variant is PROTOSS 2780; McRaveZ and McRaveT are separate variants. Author permission is outstanding for any SSCAIT derivative because the source was updated within the past year. If permission or compatibility blocks the lane, UAlbertaBot is the fallback permissive historical baseline. McRave and ZZZKBot have now completed a native Zerg cross-game; see the current [manifest](../../config/opponents.json) and port documents. Their ladder-version match and local calibration remain unknown.

For a cheap native opponent gradient, first attempt UAlbertaBot (MIT, C++, known BWAPI 4.4.0 client executable route) and the current Steamhammer line (the source page identifies 5.3.6; archive/binary matching is pending). Add ZZZKBot (LGPLv3, Zerg) as an older rush/pressure anchor if it builds. The OpenBW bot notes document a working wasm32-WASI ZZZKBot port, including 1500+ deterministic frames without a crash, but this is not evidence of a native OpenBW build; native OpenBW/bwapi still needs a direct build and smoke test. Add low-quintile Terran/Protoss leads Marine Hell (2098) and TommyBot (2069) only as later discovery targets; they are not selected as runnable opponents. Stardust is benchmark-only pending written consent.

Suggested first calibration: after build smoke tests, run only 2–4 representative pairs (one McRave, one cheap anchor, one cross-race opponent and one strong benchmark if available), with seed and map recorded. First verify that each opponent starts, sees only legal observations, issues commands, exits cleanly and emits a valid replay. Record crash/timeout separately. Do not attach any BASIL rating to a port until representative OpenBW games complete. Expand only if smoke results show engine/API gaps do not dominate.

## Evidence and interpretation

The BASIL rules page states that bots use ranks plus ELO within a rank, new bots are unranked for their first 200 games, rank changes lock for 200 games, and the ladder uses BW 1.16.1 with a 30-minute real-time limit. This means a displayed ELO is not a clean, stationary measurement and a newly uploaded version cannot be treated as calibrated immediately. BASIL also reports crashes separately; a crash or startup failure must remain its own outcome in local evaluation.
