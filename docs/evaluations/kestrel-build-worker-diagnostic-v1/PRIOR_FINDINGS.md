# Retained v12 build-worker evidence

V12 remains rejected under its registered gates. The replays narrow, but do not explain, the first-Pylon behavior. On Benzene, Probe tag `3624` accepted `Harvest1` at replay frame 2, accepted the Pylon order at frame 998 for tile `(111,15)`, and had no intervening accepted command before the Pylon became current at bot frame 1,285. On Heartbreak Ridge, Probe tag `3604` similarly accepted `Harvest1` at frame 2 and the Pylon at frame 1,202 for tile `(111,58)`; it became current at bot frame 1,315. The retained data has no worker position/order transition history, so Benzene's 289-frame interval is consistent with travel or pathing and does not establish starvation or command cancellation.

Heartbreak Ridge recorded 11 rejected build attempts, all `Unit_Busy`, but aggregate telemetry contains no frames, building types, or worker IDs and replays contain only accepted commands. Source ordering gives a testable conflict: `play()` calls `assignEconomy()` before `constructOpening()`, and `availableProbe()` can select a Probe that accepted gather earlier in that cadence when there is no established `builderId_`. This is a hypothesis until worker-level logging ties the same worker and frame to a rejected build.
