# Visibility-grid bounds source review

The pinned OpenBW BWAPI `Point<T, Scale>::isValid()` implementation rejects negative coordinates and, once `Broodwar` exists, returns `x < mapWidth * 32 / Scale && y < mapHeight * 32 / Scale` (`third_party/bwapi/bwapi/BWAPILIB/Source/Position.cpp`, lines 6–20). For `TilePosition`, `Scale` is 32, so validity is exactly the rectangular predicate `0 <= x < mapWidth && 0 <= y < mapHeight`. `GameImpl::mapWidth()` and `mapHeight()` directly return the loaded map object's width and height (`GameImpl.cpp`, lines 340–347).

Frozen McRave's `updateVisibility()` iterates x then y over `[0, 256)` and calls `isValid()` before `isVisible()` and the indexed write. Therefore the set and order of observable `isVisible()` calls is exactly x-major iteration over `[0, min(256, mapWidth)) × [0, min(256, mapHeight))`. Reading width and height once at the start of each invocation and using those loop limits preserves that order, the `TilePosition`, `isVisible()` arguments, grid index and write value. It removes only iterations for which the old short-circuit predicate was false.

Header-only inspection of retained, already-reviewed replays confirms the supported evaluation maps are below the 256 cap: Benzene 128×112, Heartbreak Ridge 128×96, Destination 96×128 and Circuit Breaker 128×128. The `min(256, dimension)` form also preserves the old iteration domain for a hypothetical loaded dimension above 256. Boundary equivalence covers negative coordinates, zero, the final map tile, the first tile outside each dimension, 255 and 256.

The only potential semantic difference would require map dimensions to change during one invocation: the old predicate queries dimensions per coordinate, while the candidate snapshots each dimension once. OpenBW runs this callback synchronously on one loaded map and its accessors return the loaded map object's dimensions; no source path mutates them during a frame. The candidate does not alter visibility cadence, x/y nesting, `isVisible`, indexing, writes, `currentGridFrame`, or any policy state.
